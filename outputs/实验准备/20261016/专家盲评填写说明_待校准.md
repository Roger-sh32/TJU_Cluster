# 专家盲评填写说明

版本日期：2026-10-16。状态：待校准工作稿，尚未用于正式评审。专家邀请、开发案例校准及正式规则锁定仍待确认；本文不表示评审已经开始或已经产生评分。

## 评价对象

请判断视频片段是否具有值得优先复盘、用于自动驾驶测试的工程价值。评价不是事故概率判断，也不是车辆安全认证。

交通参与者较多、距离较近或弯道较急，本身不等于高复核价值。请结合目标是否影响自车实际通行路线、是否造成有意义的观察/让行/避障决策等可见证据判断。正常、成功完成让行或避障，也可能具有较高复核价值；没有碰撞不等于没有交互。

只评价当前片段，不猜测视频结束后发生的事情。若关键证据缺失，请记录无法判断，不为了填满评分而猜测。

## 填写步骤

1. 先确认匿名编号与播放材料一致，并检查是否能正常观看。不要根据文件名猜测真实场景身份。
2. 独立观看并记录关键目标、时段和可见行为，不参考他人意见或外部算法分数。
3. 判断材料是否足以支持评分，再选择优先级。没有充分证据时可以使用 `NA`。
4. 填写价值机制、简短理由和判断把握，再提交本人的原始意见。不要求三位专家事先取得一致。

关键时段使用材料中标明的原始场景时间，自片段起点计时。若材料没有可靠时间标记，请写明“时间待核对”，不要把不确定的播放器进度当作精确数据时间。

## 优先级

下表沿用现有准备协议，待开发案例校准及正式锁定后使用。本轮没有新增等级或改变含义。

| 填写值 | 含义 | 判断提示 |
| --- | --- | --- |
| 0 | 常规复核价值 | 常规稳定行驶，未见值得优先复盘的特殊交互；不能仅因参与者多而提高等级 |
| 1 | 有一定复核价值 | 存在明确观察或决策任务，但交互较弱，或材料能支持有限判断而不足以支持优先复核 |
| 2 | 应优先复核 | 存在具体且有意义的路径交互、让行/避障决策、受阻改道或潜在冲突，能够指出相关目标、时段及原因 |
| NA | 无法判断 | 视频缺失、关键目标遮挡、视角不足或其他关键证据不足，无法作出可靠价值判断 |

`1` 和 `NA` 不同：前者是材料支持的有限价值判断；后者是不能可靠判断。没有看到关键目标，既不自动证明目标不存在，也不自动说明它有威胁。

## 每条记录

这里只展示记录样式，不预填场景、专家姓名、时间或评分；字段名称不是已经接通的系统导入接口。

| 记录项 | 填写要求 |
| --- | --- |
| 匿名编号 | 使用协调者提供的编号，不写入自行猜测的真实场景号 |
| 评审者编号 | 使用本人的评审编号，不代他人填写 |
| 可判断性 | 可判断或无法判断；尚未提交不是一次已完成的“无法判断”评审 |
| 优先级 | 填 `0`、`1`、`2` 或 `NA`；未完成时保持未提交，不默认填0 |
| 价值机制 | 可多选下列机制；不要为了提高等级而勉强归类 |
| 关键时段 | 尽可能给出开始/结束时间，并注明时间来源或不确定性 |
| 简短理由 | 描述目标、行为及对自车的影响，区分观察事实与推测；`NA`需写明缺失证据 |
| 判断把握 | 用文字说明判断把握或主要疑点，本稿不新增数值把握量表 |

价值机制沿用准备协议：车辆合流/切入、横向车流、VRU交互、静止障碍/避障、路口决策、施工/改道、其他、无明确机制。VRU指行人、自行车等易受伤害交通参与者。

机制是可多选的行为说明，不是评分加分表；出现某种机制不自动获得2分。“其他”请描述具体内容；若无法判断，机制也可以注明不确定，不强行给出答案。

## 缺失、补评与分歧

视频打不开、关键视角不足或时间不清楚时，请记录具体问题。协调者核对材料后可以安排补评，但补评不能覆盖原始记录；应保留原记录，并注明新记录对应哪次补评。

不同专家意见不一致时，各自原始判断仍保留。若之后组织讨论，讨论结论另行记录，不把讨论后的统一意见冒充最初的独立评分。

## 校准与正式评审

校准仅使用协调者提供的开发案例；不把校准意见当正式评价结果。正式评审材料和规则锁定后再另行发放，不能直接将当前开发回看包、带算法解释的图表或本工作稿视作已发布的正式盲评包。

本稿不含真实场景映射、算法分数、排序位置、自动语义解释、专家身份或已填评分；也没有规定算法应当优于任何对照。
